# Jori Nicole Sagario - Portfolio

Personal portfolio website for GitHub and Vercel.

## Files
- index.html
- style.css
- script.js
- images/profile.jpg

## Profile Image
Place your own profile photo at `images/profile.jpg`.

## Run
Open `index.html` in your browser.

## Deployment
Upload this folder to GitHub, then import the repository into Vercel.
